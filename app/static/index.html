Folders

Where downloaded books are imported to, and the default folder for Import Existing.

Tokens: {Author}, {Authors}, {Series}, {SeriesNumber}, {Title}, {Year}. Parts left empty (e.g. no series) are dropped.

"Title.m4b", or "Title - Part 01.mp3", "Part 02"… in disc and track order. When off, files keep their original names and subfolders.

When the downloads and the Root Folder are on the same drive, imported files take no extra space, and qBittorrent keeps seeding. Falls back to copying when they're on different drives. In Docker, both must be inside the same mounted volume. Don't use Audiobookshelf's "embed metadata" tool on hardlinked books: it would change the files qBittorrent is seeding.

Download Checks

Compares the downloaded files' total length with Audible's runtime. Mismatches wait in Activity for you to import or reject. Books without an Audible runtime aren't checked.

Needed for automatic downloads, Search Now, and sending releases from Manual Search.

Only needed when qBittorrent sees its downloads at a different path than Bayarr (e.g. separate Docker containers). Set it to Bayarr's path for qBittorrent's audiobooks save folder.

Stalled Downloads

A download with no progress (stalled, or stuck fetching metadata) for this long is rejected and the next-best release is grabbed. 0 turns this off.

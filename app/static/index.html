How to get it
  1. Log in to AudiobookBay in your browser.
  2. Open Developer Tools (F12), go to the Network tab, and refresh the page.
  3. Click the first request (the page itself), find Cookie under Request Headers, and copy its whole value.
  4. Paste it here, set the User Agent to the same browser's (or leave it), Test, then Save.

Cloudflare checks it against the cookie: use the browser the cookie came from (search "what is my user agent").

Watched Goodreads Lists

Bayarr checks these shelves every 6 hours (and when you click Check Now). New books on them are looked up on Audible and added to your library; only clear matches (title and author), so a few may need adding by hand from Search. A book you remove from the library isn't added back. The Goodreads profile must be public, unless you use the shelf's RSS link (it includes a key).

Paste the address of a shelf (open your Want to Read list on Goodreads and copy it), your profile, the shelf's RSS link, or your Goodreads user number.

Updates each imported book's metadata.json, and Audiobookshelf itself when a server and library are set above. New imports get this automatically.
